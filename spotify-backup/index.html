One-time setup

Only the person hosting this page does this. Friends never see it.

  1. Open developer.spotify.com/dashboard and pick your app (your AudioBiome one is fine).
  2. In Settings → Redirect URIs, add exactly this address, then Save:
  3. Under APIs used, make sure Web API is ticked.
  4. Paste the app's Client ID here:
  5. In User Management, add each friend's name and the email of their Spotify account. Spotify allows 5 people per app, you included.

Save a written copy of all your playlists and liked songs, in case anything ever happens to your Spotify account.

Spotify will ask if this page can see your playlists and library. It can't change anything, and your music list goes straight to this device — nothing is stored anywhere else.

First time here? Spotify only lets people who've been added use this page.

          How to get your listening data
          
                    
                
          
                
            
                    
          1. 
                        1
                        
            
                            Open Spotify's privacy page
                            
            Use a web browser (on a phone, use the browser, not the Spotify app) and log in if it asks.
            
                            
            Open spotify.com/account/privacy ↗
            
                        
            
                    
            2. 
                    
          2. 
                        2
                        
            
                            Tick what you want, then press “Request data”
                            
            Scroll down to Download your data. Tick Extended streaming history for every song you've ever played (best for all-time stats). Account data only covers the last year but arrives sooner. Ticking both is fine.
